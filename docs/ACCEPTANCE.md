## 发布前必须完成

在用户自己的 Supabase 执行 SQL，用两个真实测试用户验证相互读取/修改被拒绝；用实际金额完成建仓、成本修正、分红、部分退出与跨日补抓回放。不得用演示数据或单元测试代替这些验证。

运行至少一次云端 workflow_dispatch 并检查目标平台真实接收状态；故意让一个数据源、一个通知通道失败，确认其余基金继续核算且待发送记录留存。验证 Vercel 实际函数时限和大持仓响应体积。

使用用户明确授权上传的截图检查 Vision 提取准确性；异常、错误数字和名称歧义必须在确认界面可修正。确认微信模板字段、可用订阅额度、隐私声明、登录隔离和审核资格。
